Questions.

Quick guidance for downloading and installing an Android APK.

What is an APK file?

APK is the Android application package format used to distribute and install Android apps outside of an app store.

Which Android versions are supported?

The manifest declares minimum SDK API 26 (Android 8.0). Actual behavior can still depend on your device hardware and Android services.

Why does Android ask me to allow installation?

Android restricts installs from unknown sources by default. You may need to allow your browser or file manager to install apps. Only enable this for a source you trust.

Does the SHA-256 checksum mean the APK is safe?

No. A checksum only confirms two files are byte-for-byte identical. It is not a security scan or proof of publisher identity.

Why might installation fail?

Common causes: an unsupported Android version, low storage, a damaged download, or a conflicting app signature. Check the exact Android message before trying again.

Why does Viewny ask for notifications and biometrics?

Notifications let the app tell you when a payout moves from review to approved. Biometric access powers the optional app lock (fingerprint or screen lock, with a 4-digit PIN as a fallback). You can decline either and still log views.

How do payouts work?

You request a withdrawal from your available balance and enter your account details. Every payout is reviewed before it is approved, and you can follow its status inside the app.

How do I update Viewny?

The app includes a version check. When a newer package is published, download it from this page and install it over the existing app. Android requires an update to use the same application ID and a compatible signing key.
